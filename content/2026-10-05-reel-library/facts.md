# Shared reel library demo

Source checked 2026-10-05: local commits 8e49b81 and ba9e25f.
The renderer-neutral tardy-reel-library crate defines milestone, pipeline and
walkthrough concepts. Five project JSON libraries each supply six compatible
variants. Parameters include palette and bounded entrance timing. Seeded selection
considers recent use within the project; saved plans freeze chosen settings.
History recording is explicit and retry-idempotent, not automatic publication.
Five library tests and three composition tests pass, including 18,000 variant
frame inspections. Work is locally committed, not merged/deployed.

Visuals are actual fframes output for the same UMIE example in all three layouts;
the UMIE facts belong to the previous source-backed reel, not a new milestone.
The blue/yellow palettes are examples of selected project-owned variants.
This is a format demonstration, not live product footage or a new UMIE release.
Original ambient music from the previous batch; DM Sans under the included OFL.
No generated voice, paid media or third-party footage.

Storyboard: 0–5s hook; 5–10s milestone; 10–15s pipeline; 15–20s walkthrough.
1080×1920, 30 fps. Real layout entrance animations, readable five-second holds.
The composition renders the three layouts directly with fframes. FFmpeg normalizes
music and enables fast-start. HyperFrames-specific gates are not applicable to this chosen renderer.
Upload privately through existing asset-ID flow; never promote automatically.
