Your coding agent should feel like a conversation—not another window you have to babysit.

We built the next Tardy Agent Host slice: connect the Codex sessions already running on your machine to a persistent Tardy identity. Each session gets its own named, owner-only chat. Send a follow-up, steer ongoing work, or use /stop; replies and tool activity stream into that conversation.

Same session. Same project. Same model and sandbox. This is not a new identity for every tab, and it does not silently fork your work or approve tool requests.
